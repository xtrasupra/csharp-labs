# C# · Лабораторные работы, 2 курс

Мои учебные работы второго курса: от первых консольных программ до обработки массивов и строк.

## Содержание

В репозитории собраны **12 лабораторных работ**, исходные программы, задания и отчёты при наличии в архиве. Коллекция показывает последовательную практику базовых алгоритмов и языка C#.

| 02 | [Арифметические выражения](labs/Lab02/) |
| 03 | [Линейные алгоритмы и вычисления](labs/Lab03/) |
| 04 | [Условные операторы и выбор](labs/Lab04/) |

## Запуск

Проекты Lab01–Lab10 рассчитаны на .NET 7, Lab11–Lab12 — на .NET 10, как указано в их `.csproj`. Установите соответствующие SDK и среды выполнения либо явно перенастройте целевую платформу под своё окружение.

```bash
dotnet run --project labs/Lab01/Lab01.csproj
```

## Оформление архива

Имена папок и отчётов приведены к читаемому виду. Исключены `bin`, `obj`, IDE-кэши и дубли вложенных каталогов. Учебные решения сохранены по своей логике; результаты и ограничения следует оценивать в контексте конкретного задания.
